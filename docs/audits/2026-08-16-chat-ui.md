# Chat screen: owner review, 2026-08-16

Raised from screenshots of a live chat. Statuses: open / fixed / rejected.

## Being fixed now

1. **open** — The feed does not fade out under the floating header. A bubble
   scrolling up meets the header and is cut off hard; it should dissolve into it
   — progressive blur plus the background tone, both gathering towards the top
   edge over roughly the header's height. Telegram and the Claude app were given
   as the reference. The header itself already floats; only the gradient under it
   is missing.

   Note: a first attempt misread this as being about the context menu and
   settled that backdrop instead (7db0954). That change stands on its own — the
   menu's blur used to leave the bubbles readable as smears — but it is not what
   was asked for.
2. **open** — The back button has to be the largest and most prominent control in
   the header. It is currently the system one, so it matches every other bar
   button instead of leading them.
3. **fixed** (0449090, verified live 2026-08-16) — Deleting a message asks "for everyone / for me" in a popover that
   covers the message it is about, so it is not clear what is being deleted.
   Instead: tapping Delete enters selection mode with that message already
   selected, more messages can be added, and the confirmation sits at the bottom
   as two actions — for everyone and for me.

## Planned

4. **open** — Search inside a chat.
5. **fixed** (8530d78, f75df1b) — Tapping the status bar must go to the beginning of the chat, not to
   its end. The list is inverted, so the system behaviour lands on the wrong side.
   The input field held the tap as a second scroll view; it now declines it, and
   `testF_StatusBarTapGoesToChatStart` taps the real status bar.
6. **fixed** (556bacd, verified live 2026-08-16) — Sending a message must move the feed to the end from wherever it is
   scrolled, and play the bubble's appearance animation there. The landing is
   verified; the animation itself was not recorded, see the run report.
7. **fixed** (b390c03, 17a21be) — A bubble carrying a reaction sits unevenly: the time and the ticks
   keep different insets from the ones a plain bubble uses.
8. **fixed** (2cbaf3c) — In the context menu's selection state, dragging over the text
   should select it directly, without going through a "Select text" item first.
   The "Select text" row and the screen behind it are gone.

Run report: `docs/qa/runs/2026-08-16-chat-ui-run.md`.

## Rejected

- Swipe back does not work — reported, then withdrawn by the owner: it works.
  It works through the screen's own edge gesture; the system's interactive pop
  does not run while the header draws its own back button.
