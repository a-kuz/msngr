# Blocking and the blocked list, run

The simulator `fable-solo` (iPhone 17 / iOS 26.5) as the fixture account
`alfa`; the peer `charlie` writes headlessly through `msngrfixture send`, so
every send travels the real E2EE path against the shared stand. Screenshots
carry the session's tap grid.

- `01-chat-info-block.png` — the chat info of the direct chat: «Заблокировать»
  at the bottom, confirmed through the dialog.
- With the block on, charlie sent «Can you hear me after the block?»: his side
  shows a plain sent status (the block is not revealed to the blocked), and
  the message never appears in alfa's feed — the feed ends on the message
  before it.
- `02-blocked-bar-ru.png` — the blocked chat replaces the composer with the
  «Вы заблокировали этого пользователя. / Разблокировать» strip. The first
  take of this screen caught the strip's text in English — «You blocked this
  user.» had never entered the localization catalog; the ru entry was added in
  this change and the strip re-shot in Russian.
- `03-blocked-list.png` — Settings → «Заблокированные»: Charlie Service listed
  with an «Разблокировать» button; tapping it empties the list.
- `04-delivery-resumes.png` — after the unblock charlie's next message arrives:
  the in-app banner shows it and the chat row rides to the top of the list.
  The message sent during the block stays hidden.
- The strip's own «Разблокировать» button was also exercised (a second
  block/unblock round): the composer comes back in place of the strip.
