# A file just under 100 MB sends with its name

Run on 2026-08-27 on the `solo-live` simulator (`iPhone 17`, iOS 26.5), the
`alfa` home against a private stand on :8803, in the direct chat with Charlie.

## How

A 95 MiB file of random bytes (`big-archive.zip`) was placed into the
simulator's Files app («On My iPhone») and sent through the attachment menu's
«Файл» → the document picker.

## Seen

- The bubble appeared with the file's own name and «99,6 МБ»; within the first
  seconds the row already held `status = sent` and `seq = 22`, and the bubble
  wears the single tick.
- The stand's journal lists seq 22 with the message's clientMsgId, and the R2
  store holds the ~100 MB encrypted blob
  (`.claude/tmp/solo-stand/v3/r2/msngr-media/blobs/3804f6…`), so what left the
  device is the sealed ciphertext, not the file.
- The smaller file earlier in the same run (`quote-doc.pdf`, 15 КБ) went the
  same way, so both ends of the size range are live.

Receiving and previewing a file of this size was live earlier with a 98.9 MB
PDF (qa/runs/2026-08-21-file-preview).
