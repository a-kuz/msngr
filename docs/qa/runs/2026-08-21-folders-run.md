# Folders and tabs, run

The simulator `fable-solo` (iPhone 17 / iOS 26.5) as the fixture account
`alfa` (the reseeded trio).

- A folder «Люди» built in the editor: the name typed in, the «Люди» rule
  toggled on, «Random» and «Standup» checked in by hand.
  `01-folder-saved.png` — the folders sheet shows «Люди · 4 чатов»: the two
  direct chats by rule plus the two groups by hand.
- `02-tab-filtered.png` — a long horizontal swipe over the list switches to
  the «Люди» tab: exactly those four chats, «Design» absent, and the tab
  carries the unread badge of its own contents.
- `03-row-actions.png` — a short swipe on a row inside a folder tab adds
  «Из папки» to the usual trailing actions.
- `04-excluded-over-rule.png` — «Из папки» on Charlie, a chat that matched
  the rule: the manual exclusion wins and the row leaves the tab while the
  rule stays on.
- `05-deleted-chats-intact.png` — the folder deleted from the sheet: the tab
  bar returns to «Все | + Папка» and every chat is still in the list.
