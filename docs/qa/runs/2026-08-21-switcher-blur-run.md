# The blur in the app switcher, run

The simulator `fable-solo` (iPhone 17 / iOS 26.5) as the fixture account
`alfa`, standing in a chat with photos and text on screen. The switcher was
opened through Simulator.app's Device → App Switcher.

- `01-blurred-card.png` — the Msngr card in the switcher: the whole snapshot
  is behind a heavy blur with the app's chat glyph over it. The album's
  photos read as colour smears and not one line of text survives.
- Tapping the card returns to the chat with the blur gone.
