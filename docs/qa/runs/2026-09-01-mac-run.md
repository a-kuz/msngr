# Run: Msngr on a real Mac («Designed for iPad»), 2026-09-01

The first live run of the iOS app on macOS, on the development Mac itself
(Apple Silicon, macOS 25.5.0). No code changes were needed.

## How it was launched

```
xcodebuild -project ios/Msngr.xcodeproj -scheme Msngr \
  -destination 'platform=macOS,variant=Designed for iPad,id=<mac id>' build
```

The product lands in `Build/Products/Debug-iphoneos/Msngr.app`, signed with the
machine-local team from `ios/Config/Signing.xcconfig`. A bare iphoneos bundle is
refused by LaunchServices («incorrect executable format»); wrapping it the way
the App Store installs iOS apps on a Mac makes `open` accept it:

```
mkdir -p Msngr.app/Wrapper && cp -R <built>.app Msngr.app/Wrapper/Msngr.app
ln -s Wrapper/Msngr.app Msngr.app/WrappedBundle
open Msngr.app
```

## What was seen

- The app runs as a Mac window (591×820 pt), the chat list and the feed render,
  voice messages play, the composer takes input — `window.png` in this
  directory, and the owner watched the run live (a chat full of voice notes,
  sends acked with ticks at 18:32).
- The menu bar is the system one and carries the UIMenuBuilder menus:
  «Чаты» → «Следующий чат», «Предыдущий чат», «Изменить последнее сообщение»;
  «Формат» → «Жирный», «Курсив», «Ссылка» — read off the running app through
  System Events, so the names are the live ones, not the source's.

## Verdict

- «a menu bar on the Mac» — seen on a real Mac, promoted to done.
- «a signed run on a real Mac as Designed for iPad» — done by this run.
