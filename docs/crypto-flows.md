# Флоу первого контакта (эталон — Signal)

1. Открытие чата с новым человеком: у нас нет сессии → GET prekey-бандл(ы),
   проверка подписи SPK, X3DH, первое сообщение типа "pk" (prekey message:
   + наш identity pub + ephemeral + id использованных prekey).
2. TOFU: identity-ключ собеседника сохраняется при первом контакте.
   Любая последующая смена ключа → в чате системная плашка
   "Код безопасности изменился", исходящие блокируются до явного подтверждения
   пользователем (accept new key), кнопка сверки safety number (60 цифр/QR).
3. Ответная сторона: получает "pk"-сообщение, поднимает сессию из своих
   prekey (one-time удаляется), дальше оба на Double Ratchet ("dr").
4. Пустой чат до первого сообщения показывает карточку собеседника + плашку
   о E2E-шифровании.

# Синк контактов

- Регистрация: опциональный телефон; на сервер уходит только
  SHA-256(E.164). Discovery: POST /api/contacts/discover {hashes[]} →
  зарегистрированные userId. Приватность слабее Signal SGX — известное
  ограничение, телефоны в открытом виде не храним.
- iOS: CNContactStore → нормализация в E.164 → хэши батчем → экран
  "Контакты" со списком зарегистрированных (имя из адресной книги приоритетнее
  displayName) + приглашение остальных.
- Пересинк по pull-to-refresh и при изменении адресной книги (CNContactStoreDidChange).
